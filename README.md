# Ankit Jobanputra — Forward Deployed Product Manager

A dark premium editorial portfolio showcasing product strategy, AI-enabled workflows, technical delivery and product prototypes.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run the portfolio locally
```bash
npm install
npm run dev
``

Then open http://localhost:3000 in the same computer where the development server is running.

**Important:** `http://localhost:3000` is only the local preview of this portfolio application. It is not the Servertra website and it will not open on another person's computer. The public Servertra website is https://servertra.com/.

## Case study experience
- 18 projects in the portfolio, including the live Servertra website.
- The other 17 projects have project-specific narratives covering product strategy, users, end-to-end workflows, design trade-offs, system architecture and validation plans.
- Each project has a bespoke interface visual built for its domain, with subtle motion and responsive layouts.
- Case study chapters use animated, accessible tabs and respect reduced-motion preferences.

## Project integrity
Projects are explicitly marked as **In progress**, **Live website**, **Professional case study**, or **Concept**. Concept interfaces use illustrative sample data and are not presented as production software. Validation metrics are proposed measurement plans, not reported outcomes. Professional case studies avoid disclosing client-sensitive information.

## Deployment
Import this repository into Vercel. After deployment, connect `ankitjobanputra.com` in Vercel project settings and configure the DNS records shown there.

## Contact
Update the contact and profile links in `src/data/site.ts` before launch.
